Este proyecto corresponde a una **entrega individual** de una hoja de vida web desarrollada utilizando tecnologías web básicas.

## 📖 Cómo ejecutar el proyecto localmente

### 1. Clonar el repositorio

```bash
git clone https://github.com/JuanesIng/hoja-de-vida-web.git
```

### 2. Entrar al proyecto

```bash
cd hoja-de-vida-web
```

### 3. Abrir el proyecto

Abrir el archivo:

```text
index.html
```

También se puede utilizar **Visual Studio Code** junto con la extensión **Live Server** para ejecutar la página localmente.
